# Skin Central

Static site. Deployed with Cloudflare Pages/Workers straight from this repo.

- `index.html`  the whole site (add new packs in the `packs` list near the bottom)
- `images/`     logo and cursor (`logo.png`, `cursor.cur`)
- `sounds/`     sound effects (`click.mp3`, `hover.mp3`)
- `downloads/`  the files people download, one folder per platform
